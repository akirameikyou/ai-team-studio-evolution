# AI Team Studio Evolution — Prototype 001

A small experimental studio for testing **recognition space** as the organizing principle of AI collaboration.

## Open locally

No build step is required. Open `index.html` in a browser, or serve the folder with Python:

```text
cd C:/path/to/AI-Team-Studio-Evolution-Prototype-001
python -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765/`.

## Publish

This folder is designed to be copied to a GitHub repository and served by GitHub Pages. The repository should preserve the source, protocol, and development history together with the live prototype.

## First experiment

Have GPT, Claude, Gemini, and Codex independently inspect the same published artifact. Collect their observations before exposing their reports to one another. Then create the difference record and decide what enters Prototype 002.
