# LIMITATIONS

- External AI APIs are not connected.
- Automatic task dispatch is not yet connected.
- Automatic result collection is not yet connected.
- SOURCE retrieval and SHA verification are manual.
- localStorage is local to the browser.
- Case Packet is a transport format prototype, not yet a network protocol.
- AI independence still depends on operational procedure.
- The next experiment is to connect a real AI observer to the Case rather than to add more UI.
- The competition submissions (canonical ZIPs) referenced by CASE-001 are not included in this public version; their SOURCE entries must be registered by the user.
- Human Gate is a single Case-level state (APPROVE / HOLD / REVISE); it is not tied to individual observer results.
- Case Packet import replaces the whole current Case after confirmation; there is no merge.
